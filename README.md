## Run Files

Run any example from the repository root with `dart run <file>`.

| File | Command |
| --- | --- |
| `bin/age.dart` | `dart run bin/age.dart` |
| `bin/control_flows.dart` | `dart run bin/control_flows.dart` |
| `bin/functions.dart` | `dart run bin/functions.dart` |
| `bin/grading.dart` | `dart run bin/grading.dart` |
| `bin/quadratic_solver.dart` | `dart run bin/quadratic_solver.dart` |
| `bin/string.dart` | `dart run bin/string.dart` |
